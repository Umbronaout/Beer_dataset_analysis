# Beer_dataset_analysis
A school project focused on beer data analysis using machine learning methods.

dataset aviable on Kaggle:
https://www.kaggle.com/datasets/gauravharamkar/beer-data-analytics/data

Reads data from the .csv of the dataset.
Performs sentiment analysis using Textblob if use_polarity = True.
Performs clustering of the beer styles if use_beer_styles = True.
Uses KNN, MLPRegressor and Random Forest Regressor to predict the final review score for the beer.
Saves visualizations of  beer style clustering and final predictions
